# 💕 Love-nfc

Ein schönes Projekt, das "Ich liebe dich" in verschiedenen Sprachen weltweit anzeigt.

## ✨ Features

- 🌍 **45+ Sprachen** - Unterstützt Sprachen aus der ganzen Welt
- 🎲 **Zufällige Auswahl** - Jedes Mal, wenn du die Seite öffnest, wird eine neue Sprache angezeigt
- 🌐 **Länderangabe** - Jede Nachricht zeigt das Land/die Region mit Flagge-Emoji an
- 💫 **Moderne Animation** - Schöne Übergänge und Animationen
- 📱 **Responsive Design** - Funktioniert auf allen Geräten (Desktop, Tablet, Handy)

## 🚀 Verwendung

Öffne einfach die `index.html` Datei in deinem Browser. Die Seite wird automatisch eine zufällige Sprache anzeigen.

Du kannst auch auf den Button "Neue Sprache laden" klicken, um eine neue zufällige Sprache anzuzeigen.

## 📂 Dateien

- `index.html` - Die Haupt-HTML-Datei
- `script.js` - JavaScript mit allen Sprachen und der Zufallslogik
- `styles.css` - Styling und Animationen
- `README.md` - Diese Datei

## 🎨 Anpassung

Du kannst leicht neue Sprachen hinzufügen, indem du neue Einträge in das `loveMessages` Array in `script.js` hinzufügst:

```javascript
{ text: "Deine Phrase hier", country: "🇩🇪 Sprache (Land)" }
```
